Cliente do **Balaiak OT** (8.60) já configurado para `balaiak.servegame.com`.

| Sistema | Arquivo |
|---|---|
| Windows 10/11 (64 bits) | `Balaiak-OT-Windows.zip` → abra `Balaiak-OT.exe` |
| Linux (Ubuntu 24.04 ou mais novo) | `Balaiak-OT-Linux.tar.gz` → rode `./Balaiak-OT` |
